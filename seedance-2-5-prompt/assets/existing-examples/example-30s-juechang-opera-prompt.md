# Seedance 2.5 可投喂版｜30秒 民国戏曲短剧《绝唱》

30秒，9:16竖屏，24fps，无字幕，无现代UI/Logo/水印；无BGM，只用戏曲唱腔、环境音与枪声。

【导演意图】
以《霸王别姬》为戏中戏，讲一对夫妻在战争年代的约定：妻子登台唱别离，丈夫被困城外牺牲；两人带伤重逢，一同走向戏台出口并消失。铜镜贯穿约定与重逢。

【参考素材职责】
@图片1 只负责妻的脸与虞姬妆造；@图片2 只负责夫的外形；@图片3 只负责戏台、后台、城门场景；均不继承文字、水印、光线。

【人物锁】
妻：民国戏曲花旦，年轻东方女性，鹅蛋脸，细长凤眼，柳叶眉，眼下小痣，黑色盘发插珠钗；虞姬扮相。生前死后同一张脸，只增加嘴角血迹与左胸弹孔。
夫：民国青年军官，深灰军装，短发，眉目端正。生前死后同一张脸，只增加嘴角血迹与左胸弹孔。
大佐：日军大佐，中年男性，军装佩刀，坐观众席中央。全片只有这三位清晰人物；日军士兵只作中远景群像。

【场景与空间锁】
后台化妆间：铜镜、油灯、梳妆台、戏服架。戏台：红色幕布、木地板、灯笼、侧幕。台下：日军士兵成排端坐。城外：民国城门、硝烟、火把、避难人群。
光线：后台暖黄，戏台明亮，城外冷蓝，重逢旧幕转暖金。

【时间轴】

0-3秒｜后台约定
第一帧已是铜镜前双人画面：妻穿戏服坐妆台前，夫站身后擦去她的眼泪；两人在镜中对视，同一画面容纳双方视线。夫说“你卸妆前我一定到”，随后转身离开。
镜头：铜镜双人中景，固定机位缓慢推近，不分屏不叠画。声音：油灯噼啪、衣料摩擦、低声承诺。

3-6秒｜登台
妻擦泪，从侧幕拉开红色幕帘登台；台下是一排排日军士兵，大佐坐中央。旁白：“皇军进城，要唱一场欢迎戏。”
镜头：侧幕跟拍登台 → 舞台上全景望向台下日军。声音：幕布、木地板脚步声、士兵低语、旁白。

6-9秒｜唱词与逆行
妻唱“汉兵已略地，四面楚歌声”，水袖甩开；切城外，夫穿过硝烟与人群奔向城门。
镜头：舞台中近景 → 城外手持跟拍。声音：唱腔、锣鼓点、奔跑脚步、远处枪炮。

9-12秒｜中枪
夫在城门附近被击中左胸，慢镜中倒下；妻的唱腔继续飘远。
镜头：正面中景，慢镜表现左胸中弹，不拍伤口内部。声音：枪声、风声、唱腔渐远。

12-15秒｜大佐叫停
切回舞台：妻唱“大王意气尽，贱妾何聊生”；大佐突然站起喊“停下！”
镜头：舞台侧面视角，同时看到台上的妻与台下的日军。声音：唱腔骤停、大佐喊声、座椅响动。

15-18秒｜枪杀
妻再唱“大王意气尽，贱妾何聊生”；大佐开枪，子弹击中妻左胸，妻倒下，台上只剩一把剑。
镜头：侧面中景 → 舞台全景，红幕与剑同框。声音：枪声、倒地声、短暂静默。

18-22秒｜旧幕时光
切到侧幕：崭新红幕快速变为布满灰尘的旧幕，灰尘扬起；幕布重新拉开，妻妆容未变，只是嘴角带血、左胸有弹孔，唱完最后一句“大王意气尽，贱妾何聊生”。
镜头：幕布固定机位 → 开幕后缓慢前推。声音：幕布摩擦、灰尘、唱腔。

22-26秒｜夫现与约定
夫从旧幕侧走出，妆容与军装未变，嘴角带血、左胸有弹孔；他坚定地说“你卸妆前我一定到”。
镜头：旧幕前双人中景，光线转暖金。声音：脚步声、呼吸、男声。

26-30秒｜走向出口
夫扶起妻说“一起走向戏台的出口”；两人并肩走向舞台出口，身体从脚开始慢慢向上消失；切铜镜，镜中倒影同步淡去，红幕缓缓合拢。
镜头：侧后方跟拍 → 铜镜固定机位，停留约1秒自然收尾。声音：衣料、脚步声渐弱，环境声淡出。

【摄影与质感】
民国旧胶片质感：轻微颗粒、漏光、低饱和；真实肤色，不做商业磨皮；手持与固定机位交替，无广告式环绕运镜。

【连续性】
妻和夫生前死后保持同一张脸、同一妆造、同一服装，只增加嘴角血迹与左胸弹孔；左胸中弹位置全程一致，不左右镜像。
铜镜、红色幕布、舞台上的剑作为贯穿符号：铜镜出现在开头与结尾，幕布从新变旧，剑留在空舞台。
除妻、夫、大佐外无其他清晰人脸；日军士兵无面部特写。
