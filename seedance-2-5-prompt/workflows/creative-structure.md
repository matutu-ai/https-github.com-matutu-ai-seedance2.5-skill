# Creative Structure Engine

根据视频目的、产品类型、时长、平台和用户 Brief 动态决定结构。不要把 10 秒、15 秒、30 秒写死成固定结构。

## 动态选择

输入决定结构：

- 时长：决定段数上限。
- 目的：决定叙事顺序。
- 产品类型：决定展示重点。
- 平台：决定节奏和首帧强度。
- 用户 Brief：最高优先级。

常用骨架只作为模板：

| 时长 | 可参考骨架 |
|---|---|
| 10秒 | 钩子 → 核心动作/对白 → 收束 |
| 15秒 | 场景建立 → 人物出场 → 产品时刻 → 情绪高潮 → 过渡 → 品牌定格 |
| 30秒 | 钩子 → 世界建立 → 产品触发 → 证明 → 情绪兑现 → 品牌收束 |

结构可拆分、合并或调整，只要每个时间段满足 `SHOT / ACTION / CAMERA / AUDIO` 四要素。

## 多概念机制

用户没有指定创意时，生成 3 个创意方向：

```text
Concept A
Concept B
Concept C
```

每个概念包括：

```text
创意名称
核心 Hook
视频逻辑
产品植入方式
视觉风格
结尾
```

然后推荐 `BEST CONCEPT`，再进入分镜。

用户已经明确指定创意时，不重复生成 3 个方案，直接进入执行。

## 输出

填充 `creative` 字段：`concept_name`、`structure`、`hook`、`product_integration`、`visual_style`、`ending`，必要时填 `variants`。
