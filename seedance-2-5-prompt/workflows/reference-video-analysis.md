# Reference Video Analysis

用户提供参考视频时，先拆解结构，再生成原创方案。不要机械复制参考视频。

## 拆解字段

```text
0-3秒 Hook
镜头数量
镜头长度
景别
运镜
主体动作
产品出现时间
产品展示方式
人物动作
声音
字幕
转场
节奏
情绪
结尾
CTA
```

## 拆解流程

```text
Reference Video
↓
Structure Analysis
↓
Creative Pattern
↓
Original Concept
↓
New Storyboard
↓
Seedance Prompt
```

## 学习范围

只学习：

```text
结构
节奏
镜头语言
内容机制
```

产品、人物、场景、台词、具体动作必须替换为本次项目的真实素材和卖点。

## 输出

参考拆解进入 `input` / `creative` 的分析备注，不直接进入最终 Prompt；最终 Prompt 使用原创故事板。
