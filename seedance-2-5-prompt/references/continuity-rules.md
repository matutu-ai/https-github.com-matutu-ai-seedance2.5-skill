# Continuity Rules

## 人物

脸、年龄感、发型、发色、肤色、体型、服装、鞋、配饰、标志性特征全程不变。人物固定特征只定义一次，时间轴只写本镜新增动作。

## 产品

外观、数量、位置、状态、Logo、文字全程一致。禁止产品突然变色、凭空消失、复制、穿模。

## 场景

空间布局、光线、时间全程一致。空间变化要有明确转场依据。

## 动作

左右方向、运动轨迹、前后关系一致，不错误镜像。开门方向、朝向、左右手必须锁定。

## 摄影

镜头方向、镜像、景别衔接合理。不做无依据的镜头翻转。

## 禁止项

```text
人物突然换脸
产品突然变色
产品凭空消失
产品复制
手指异常
物体穿模
左右方向错误
```

## No-Face / Face Policy

用户要求 NO FACE / NO CLEAR FACE / PRODUCT ONLY / HANDS ONLY / BACK VIEW / SILHOUETTE 时，必须同时写入：

```text
CHARACTER LOCK
CAMERA
SHOT
NEGATIVE
```

不能只在人物锁写一次。
