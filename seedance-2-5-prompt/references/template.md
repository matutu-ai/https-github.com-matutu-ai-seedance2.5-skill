# Seedance 2.5 可复用提示词模板

结构顺序：规格 → 导演意图 → 素材职责 → 锁 → 时间轴 → 摄影/声音 → 负面约束 → 结尾状态。

## 模板

【规格】
<时长>秒，<画幅>，<帧率>，字幕：<有/无>，背景音乐：<有/无>，旁白：<有/无>。

【导演意图】
一句话说明成片气质。

【参考素材职责】
@图片1：只负责<角色外观/产品外观/场景布局/材质>；不继承<背景/文字/Logo/水印/光线/人物>。
@图片2：<同样写清“负责什么+不负责什么”>。

【人物锁】
<角色名>：同一张脸，<固定特征>，<发型>，<服装>，<鞋>。全片唯一清晰人物/第N号人物，年龄感与外形全程不变。

【场景与空间锁】
<地点>。固定空间关系：<门在X/吧台在X/窗在X>。时间与光线：<清晨/夜晚/室内/室外>，<对比度>。

【时间轴】
每段写：时间 / 镜头 / 画面动作 / 声音。

<0-3秒｜钩子>
第一帧已在动作中间：<具体动作>；0.7秒内触发<事件>；3秒内状态改变：<改变>。
镜头：<景别+运镜>。声音：<环境音+音效>。

<3-6秒｜展开>
<核心动作/对白，标注起止时间>。声音：<人声+环境音>。

<6-10秒｜收束>
<结尾动作>，画面<轻微前推/固定/跟拍>，保留<环境音>约1秒自然收尾。

【摄影与质感】
<风格关键词：手持DV/16mm/35mm胶片/商业片/纪录片>；<光线曲线>；<肤色与磨皮规则>。

【声音】
环境音层：<店内/户外/机器声>。
音效层：<动作音效清单>。
人声层：<对白内容，起止时间，repeat_count=1，不回声不重复>。
BGM：<无/有，起止时间>。

【连续性】
人物一致性：<锁外貌/服装/鞋>。
道具规则：<数量，不消失/不复制/不悬浮>。
走位与镜像：<固定方向，不错误镜像>。

【负面约束】
只写高风险项：不变形、不换脸、不穿帮、不重复钩子动作、无字幕/Logo/水印、无多余UI。

【结尾状态】
<最后1-2秒的画面定格或自然收尾>。

## 对白锁定写法

对白较多时，在规格后加【口播台词表｜逐字锁定】：

句1（<说话人>，<起止时间>，<口吻>）：<逐字台词>
句2（...）：...

并附硬规则：逐字按表输出；禁止改字、漏字、同音替换、自行发挥；每句只出现一次；语速宁慢勿错；旁白与本人同一把声。
