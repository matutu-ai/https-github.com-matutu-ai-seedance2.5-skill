# Test 06｜已有 Prompt 优化

## 输入

已有 Prompt：一段时间轴混乱、动作过载、连续性缺失的 Seedance Prompt。
要求：保留原始创意，修复时间轴、动作过载、连续性。

## 期望输出

```text
ANALYZE: 定位弱点
PRESERVE: 保留原始创意与卖点
REPAIR: 时间轴、动作拆镜、连续性锁
COMPILE: 新 Prompt
QA: READY
```

## 验收标准

- [ ] 原始创意未被无理由改变。
- [ ] 每个镜头动作负载 LOW-MEDIUM。
- [ ] 时间码连续无断层。
- [ ] 人物/产品/场景锁完整。
- [ ] QA 标记 `READY`。
