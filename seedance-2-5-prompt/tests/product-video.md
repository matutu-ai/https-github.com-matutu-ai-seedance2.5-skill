# Test 01｜运动摇摇杯产品视频

## 输入

产品：运动摇摇杯。
卖点：密封防漏、杯身刻度、搅拌球、便携提环、易清洗。
要求：产品多视角、不出现人物面孔、TikTok 竖屏、10 秒。

## 期望输出

```text
SPEC: 10秒，9:16，无字幕，无BGM
PRODUCT LOCK: 形状/比例/颜色/材质/刻度/Logo/提环/搅拌球数量不变
SCENE LOCK: 运动场景或简洁背景
STORYBOARD: front / side / detail / in-use 多视角
CAMERA: 每个视角单一主运镜
SOUND: 环境音 + 产品动作音
CONTINUITY: 同一产品，不消失/不复制
NEGATIVE: no clear face, no product redesign, no mirror error
ENDING: 产品定格
```

## 验收标准

- [ ] 全片无清晰人脸，只允许手部或产品特写。
- [ ] 多视角来自同一个产品，产品设计不漂移。
- [ ] 每个镜头动作负载 LOW-MEDIUM。
- [ ] QA 标记 `READY`。
