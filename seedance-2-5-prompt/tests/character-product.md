# Test 03｜人物使用产品

## 输入

产品：便携咖啡机。
人物：25 岁亚洲女性，黑色高马尾，深色运动服，白色运动鞋。
要求：人物一致、产品一致、连续动作。

## 期望输出

```text
CHARACTER LOCK: 脸/发型/服装/鞋不变
PRODUCT LOCK: 外观/颜色/Logo/配件不变
STORYBOARD: 人物取机 → 装豆/加水 → 按压 → 出杯
CAMERA: 中景到近景，单一主运镜
CONTINUITY: 左右手、杯量、产品状态一致
```

## 验收标准

- [ ] 人物全程同一张脸、同一服装。
- [ ] 产品状态按步骤变化，不跳变。
- [ ] 动作连续，无穿模、无重复肢体。
- [ ] QA 标记 `READY`。
