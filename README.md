# seedance2.5-skill

Seedance 2.5 可投喂提示词技能库。

## 内容

- `seedance-2.5-prompt-template.md`：可直接复制套用的最新框架模板。
- `seedance-2-5-prompt/`：Codex 技能包，安装后可直接生成可投喂提示词。
- `seedance-2-5-prompt/references/template.md`：技能内置模板。
- `seedance-2-5-prompt/references/checklist.md`：生成后逐项质检清单。
- `seedance-2-5-prompt/assets/`：可直接投喂示例（10秒韩语咖啡馆、15秒日立电梯、16秒动作片、30秒短剧）。

## 快速使用

复制 `seedance-2.5-prompt-template.md`，按顺序填写：
规格 → 导演意图 → 素材职责 → 锁 → 时间轴 → 摄影/声音 → 负面约束 → 结尾状态。

对白较多时加【口播台词表｜逐字锁定】，品牌名和生僻词附拼音。
